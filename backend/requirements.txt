# --- database ----------------------------------------------------------------
# Async throughout: Week 6 pushes over Socket.IO and Weeks 7-10 make LLM/RAG
# calls, all of which are I/O-bound. A synchronous session inside an `async def`
# route blocks the whole event loop, so going async now avoids a rewrite later.
sqlalchemy[asyncio]>=2.0.30,<3.0.0
asyncpg>=0.29.0,<0.31.0
geoalchemy2>=0.15.0,<0.18.0    # Geography(POINT, 4326) column + ST_* functions
alembic>=1.13.0,<2.0.0

# psycopg2 is NOT needed. asyncpg is the driver; Alembic is configured for async
# in migrations/env.py. Installing psycopg2-binary alongside is a common way to
# end up with two drivers and a confusing "wrong DBAPI" error.
